## TMDB — film data and posters

All film data (titles, genres, keywords, directors, countries, runtimes, ratings,
recommendations) and poster images come from [The Movie Database
(TMDB)](https://www.themoviedb.org/), via the
[TMDB API](https://developer.themoviedb.org/), under the
[TMDB API Terms of Use](https://www.themoviedb.org/api-terms-of-use).

<a href="https://www.themoviedb.org/"><img src="assets/tmdb-logo.svg" alt="The Movie Database (TMDB)" width="160"></a>

> This application uses TMDB and the TMDB APIs but is not endorsed, certified, or
> otherwise approved by TMDB.

The same notice and logo appear inside the app. blendboxd is free and
non-commercial. Each browser caches the TMDB data it fetches for at most 150 days,
inside TMDB's six-month limit. The TMDB logo (`assets/tmdb-logo.svg`) is TMDB's
own and is used only to credit TMDB.

## Letterboxd

blendboxd reads the data exports people download from their own
[Letterboxd](https://letterboxd.com/) accounts. It is not affiliated with,
endorsed by or connected to Letterboxd; the name only nods to it. blendboxd does
not access Letterboxd itself.

## fflate

Zip files are opened in the browser with [fflate](https://github.com/101arrowz/fflate)
0.8.2 by Arjun Barrett, used under the MIT License. The file `vendor/fflate.js`
carries its full license text.
